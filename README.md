# 易经研习

一个易经知识与练习的 Web 应用（Golang 后端 + 纯静态前端）。

## 功能

- **首页**：先天八卦图与后天八卦图（SVG 绘制，悬停查看卦义）
- **奇门练习**：天盘干加地盘干八十一格（十干克应），随机出题四选一，附格局详解、总览查阅与《烟波钓叟歌》全文
- **奇门排盘**：时家转盘奇门（拆补法），依公历时刻排四柱、三元、局数、天地盘、九星八门八神，标注旬空、马星与五不遇时（历法由 tyme4ts 提供）
- **长生练习**：十天干十二长生，随机落干于洛书九宫（除中五宫），依口诀断其旺衰状态，附全表速览
- **六十四卦**：卦图与卦名对应练习（看图选名 / 看名选图），附卦辞、卦义详解与总览弹窗

## 运行

```bash
go run main.go
```

浏览器访问 <http://localhost:8080> 即可。

## 目录结构

```
yx/
├── main.go          # HTTP 服务，托管 static 目录（:8080）
├── go.mod
└── static/
    ├── index.html       # 首页：先天 / 后天八卦图
    ├── basics.html      # 卦象知识：卦爻体例 / 卦变四法 / 十二辟卦等
    ├── qimen.html       # 奇门遁甲八十一格练习（附《烟波钓叟歌》）
    ├── pan.html         # 奇门排盘：时家转盘拆补法
    ├── changsheng.html  # 十天干十二长生练习
    ├── gua64.html       # 六十四卦图名对应练习
    ├── lib/tyme.js      # tyme4ts 历法库（四柱 / 节气推算）
    └── style.css        # 共享暗色主题（玄青墨蓝）
```
