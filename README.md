# 易经研习

一个易经知识与练习的 Web 应用（Golang 后端 + 纯静态前端）。

## 功能

- **首页**：先天八卦图与后天八卦图（SVG 绘制，悬停查看卦义）
- **奇门练习**：天盘干加地盘干八十一格（十干克应），随机出题四选一，附格局详解与总览查阅
- **长生练习**：十天干十二长生，随机落干于洛书九宫（除中五宫），依口诀断其旺衰状态，附全表速览

## 运行

```bash
go run main.go
```

浏览器访问 <http://localhost:8080> 即可。

## 目录结构

```
yx/
├── main.go          # HTTP 服务，托管 static 目录（:8080）
├── go.mod
└── static/
    ├── index.html       # 首页：先天 / 后天八卦图
    ├── qimen.html       # 奇门遁甲八十一格练习
    ├── changsheng.html  # 十天干十二长生练习
    └── style.css        # 共享暗色主题（玄青墨蓝）
```
